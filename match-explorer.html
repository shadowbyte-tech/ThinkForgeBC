NET VALUE FORMULA DEMO METHODOLOGY

The ResourceX Net Value is calculated as follows:

Net Value = Gross Offer - Freight(Distance × Rate) - Processing Cost - Handling Fee

This simulation uses indicative freight rates and processing deductions. Final settlement values are subject to buyer inspection, physical weighbridge certificate, and bilateral agreement. All figures shown are simulated for platform demonstration.
